# planner2do

Task planner with a React/Vite web app, Firebase integration, and an Electron desktop wrapper.

## Explore and run

The web application lives in `planner/`; `planner-desktop/` contains the Electron wrapper. See [the web-app guide](planner/README.md) for Firebase configuration and existing features.

```sh
npm --prefix planner install
npm --prefix planner run dev
```

For a web build, run `npm --prefix planner run build`. Desktop packaging is separate and requires the web build assets.
